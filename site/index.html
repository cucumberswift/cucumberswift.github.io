Cucumber for iOS, tvOS and macOS

Describe it in Gherkin. Prove it in Swift.

CucumberSwift is a lightweight, Swift-only Cucumber implementation. Your .feature files run as XCTest tests, right alongside the rest of your suite in Xcode.

How it works

From a sentence to a passing test in three steps

  1. 1

    Describe the behaviour

    Write scenarios in .feature files that product, QA and engineering can all read. Keywords are localised, so the Gherkin can be in your team's language.

  2. 2

    Match each step

    Bind steps with Given, When and Then, using Cucumber Expressions with type-safe parameters, or regular expressions.

  3. 3

    Run it with XCTest

    Scenarios run as ordinary tests. Steps you haven't written yet come with generated stubs to paste into your step definitions.

What's included

Small on purpose

CucumberSwift was written to be easy to install and easy to use. It covers what a Swift team needs from Cucumber, and not much else.

  • Cucumber Expressions

    Readable patterns like {int} and {string}, plus your own typed parameters.

  • Six hooks

    Before and after each feature, scenario and step, for setup and clean-up.

  • JSON reports

    A Cucumber JSON report written in real time while your tests run.

  • Localised Gherkin

    Keyword functions in every Gherkin language, such as ES_Dado for Spanish.

Install

Add it to your test target

In Xcode, choose File › Add Package Dependencies… and paste the repository URL. Or add it to Package.swift. Carthage is supported too.
